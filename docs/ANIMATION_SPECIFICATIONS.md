# Motion specifications

Authority: KennyMotion.h, ClaudeTheme.h, KennyControls.h and KennyAurora.h.

| Motion | Native rate | 95% settling time |
|---|---:|---:|
| Hover |18|167ms|
| Tab selection |15|200ms|
| Check |22|136ms|
| Slider display |24|125ms|
| Touch position |14|214ms|
| Touch illumination rise |7|428ms|
| Illumination release |2.8|1070ms|

Interpolation a+(b−a)(1−exp(−rate×dt)); dt≤.1. App checkbox follows rate22; Android buttons use rate18 emphasis and circular checks use rate22. Lab navigation updates locally and is not claimed a faithful moving underline port. Aurora model is fixed120Hz; reduced motion stops ambient simulation. No application-specific transitions are invented before the video. See Aurora guide for geometry and timing formulas.
